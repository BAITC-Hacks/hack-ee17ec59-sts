# Границы районов Астаны

`astana_districts.geojson` хранится локально и содержит пять районов из контракта проекта.

## Обновление Алматы — 23 сентября 2026

Применён способ 1: реальная граница OpenStreetMap, relation [3482819](https://www.openstreetmap.org/relation/3482819), `boundary=administrative`, `admin_level=6`.
Названия OSM: `name=Алматы ауданы`, `name:ru=район Алматы`, `name:en=Almaty District`, `alt_name:ru=Алматинский район`. Тег `name:kk` отсутствует.
Город Астана — relation [3087155](https://www.openstreetmap.org/relation/3087155), `admin_level=4`; `name`, `name:ru`, `name:kk` равны «Астана».

Overpass вернул HTTP 406/504 либо таймауты, поэтому геометрия загружена из официального [OSM API relation/full](https://www.openstreetmap.org/api/0.6/relation/3482819/full.json).
Участники relation (ways и nodes) собраны Shapely `polygonize` в замкнутые внешние кольца, внутренние кольца вычтены. Получен валидный MultiPolygon без упрощения, обрезки и восстановления остатком города.
`properties.id="almaty"`, `name="Алматы"`, `schematic=false`, `source="OpenStreetMap"`; центр пересчитан. Предупреждение о схематичной границе больше не применимо. Геометрии остальных четырёх районов не изменены.

Площади рассчитаны в EPSG:32642 (WGS 84 / UTM zone 42N):

| Район | Площадь, км² |
|---|---:|
| Есиль | 194.544737 |
| Алматы | 93.379126 |
| Сарыарка | 67.812755 |
| Байконур | 183.487734 |
| Нура | 188.545271 |

Все пять геометрий валидны. Площадь пересечений для всех десяти пар равна 0 км²; общие границы допустимы. Алматы сопоставим по площади с остальными районами. Машиночитаемый отчёт: `almaty-validation.json`.

Полную актуальную выборку административных relations внутри area Астаны получить не удалось из-за ошибок Overpass. Не следует считать прежнюю bbox-выборку `metadata.found` исчерпывающим списком внутри города. Запрос для повторения:

```overpass
[out:json][timeout:60];
rel(3087155);out tags;
map_to_area->.city;
rel(area.city)[boundary=administrative];out tags;
```

Модель содержит пять районов и не является полным современным административным делением города: отдельно существующий район Сарайшык не входит в контракт.

Источник: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0. Источник и время обновления Алматы записаны отдельно в `metadata.almaty_update`; исходные сведения о загрузке остальных районов сохранены.

Старая версия сохранена локально как `astana_districts.backup.geojson` и исключена из Git.
Временные Python/Shapely/pyproj использовались только в `.venv`; зависимости приложения не менялись.
