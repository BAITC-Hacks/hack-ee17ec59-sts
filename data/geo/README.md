# Границы районов Астаны

`astana_districts.geojson` хранится в Git и читается приложением локально.
В выборку входят только пять районов из контракта проекта.

Overpass обнаружил: район Есиль (3479876), район Алматы (3482819),
район Сарыарка (3486954), район Байконур (8593081), район Нура (20593940).
У всех пяти `admin_level=6`. Найденный отдельно район Сарайшык не входит
в заданную модель из пяти районов: карта не является полным актуальным
административным делением города.

**Границы схематичные для Алматы**: relation найдена, но скачивание геометрии
завершилось HTTP 504 / таймаутами на трёх Overpass-серверах. Это не означает
отсутствия района в OSM. Для него сохранён небольшой прямоугольник вокруг
приблизительного центра (71.51, 51.145), а не административная граница.
Полигоны остальных районов взяты из OSM и проверены на замкнутость,
валидность, диапазон координат, площадь и взаимные пересечения.
`properties.schematic` явно отмечает fallback; предупреждение показывается
и в интерфейсе. Поле `centroid` содержит геометрический центр полигона.

Источник: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright),
ODbL 1.0. Relation ID, время выгрузки, найденные названия, `admin_level`
и сетевые ошибки сохранены в самом GeoJSON.

## Одноразовая загрузка

Из корня репозитория, в установленном Python-окружении:

```sh
python -m pip install shapely
python scripts/fetch_districts.py
```

Shapely нужен только скрипту загрузки для проверки геометрии. Streamlit-карта
использует зависимости из существующего `requirements.txt`. В рантайме
запросов к Overpass нет. Подложка `open-street-map` загружает тайлы в браузере
и требует интернет, но не требует токенов.

## Подключение

```python
from app.map_view import render_map

render_map([{"id": "M7", "district": "nura"}, {"id": "M12", "district": None}])
```

Все значения симуляции поступают через `engine/interface.py`. Текущая
заглушка возвращает только Нуру и два показателя; карта не восполняет
отсутствующие расчёты и отмечает неполные данные. Полный результат движка
автоматически включает все три слоя, подсчёт показателей < 40 и ухудшения.
