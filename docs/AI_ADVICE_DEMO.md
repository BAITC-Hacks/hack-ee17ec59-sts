# Проверка AI-совета и кнопки применения

## Ключ и запуск

1. Откройте локальный `.env.local` в корне проекта и заполните только `LLM_API_KEY` своим ключом OpenAI. Этот файл исключён из Git; ключ не добавляйте в документацию, JSON сценария или команды проверки.
2. Оставьте `LLM_MODEL` и `OPENAI_MODEL` равными `gpt-5.4-mini`, а `LLM_BASE_URL` — `https://api.openai.com/v1`. `OPENAI_API_KEY=${LLM_API_KEY}` передаёт тот же локальный ключ старому маршруту записки акиму; копировать ключ в две строки не нужно.
3. Остановите запущенный dev-сервер и запустите его снова из корня проекта: `npm run dev`. Откройте `http://127.0.0.1:3000/`.

## Проверка в браузере

1. Нажмите **«Загрузить эталонный сценарий»**, затем **«Рассчитать сценарий»**. Исходные решения: M7, M8 и M10 в Нуре, M12 для всего города, M5 в Сарыарке.
2. В карточке **«AI-заместитель акима»** нажмите **«Получить совет»**.
3. Проверьте источник объяснения: **«AI-объяснение»** означает успешный ответ модели; **«Объяснение по расчёту»** означает резервное объяснение. Резервный режим работает без ключа и при ошибке модели; расчёт и применение совета доступны в обоих режимах.
4. Сравните решение, Score, расходы и компромисс. Для текущего каталога ожидается замена **M5 в Сарыарке → M14 для всего города**: Score **56.54 → 56.99**, расходы **95 → 86**, балл Сарыарки **56.30 → 55.70**. Это ожидаемые значения для проверки; источники чисел — `data/*.json` и движок, а не этот документ или текст модели.
5. Нажмите **«Применить совет»**. В пятом слоте должна появиться M14 **«Аварийные бригады ЖКХ + оповещение»** без выбора района. Бюджет и результаты должны обновиться сразу.
6. Нажмите **«Отменить совет»**. Проверьте возврат M5 в Сарыарку, расходов 95 и Score 56.54.
7. Ещё раз получите совет, затем вручную измените район одной из мер до применения. Старый результат и совет должны исчезнуть. После нового расчёта требуется новый совет; прежний нельзя применить к изменённому плану.

## Тот же запрос через PowerShell

Выполняйте из корня проекта при работающем сервере. Файл `docs/examples/advice-scenario.json` содержит тот же эталонный сценарий в формате запроса `POST /api/advice`.

```powershell
$adviceResult = Invoke-RestMethod `
  -Uri "http://127.0.0.1:3000/api/advice" `
  -Method Post `
  -ContentType "application/json" `
  -InFile ".\docs\examples\advice-scenario.json"

if ($adviceResult.source -notin @("openai", "fallback")) {
  throw "Неизвестный источник объяснения."
}
if ($null -eq $adviceResult.proposal -or
    @($adviceResult.proposal.baseScenario.decisions).Count -ne 5 -or
    @($adviceResult.proposal.scenario.decisions).Count -ne 5) {
  throw "Для эталонного сценария ожидался совет с исходными и новыми пятью решениями."
}

$adviceResult | Select-Object source, explanation
$adviceResult.proposal.scenario.decisions | Format-Table measureId, districtId
```

Команда выводит источник, объяснение и предложенные решения. Ключ читает сервер из `.env.local`; в запрос он не передаётся и в вывод не попадает. Запрос API сам не меняет сценарий в браузере: примените совет кнопкой в интерфейсе.
