# Akim-5 — план проекта (хакатон 5 часов)

Задача: «Аким на 5 часов» — AI-симулятор управления городом (Astana Innovations).
Пользователь принимает 5 решений в рамках бюджета 100 → Astana Quality of Life Score + AI-объяснение.
Время ниже — от старта хакатона (T+ч:мм). Время старта и имена — в docs/status/META.md.

## Команда и зоны
| Зона | Кто | Отвечает за |
|---|---|---|
| engine | Lix | движок, данные, оптимизатор, Парето, таймлайн, карта, AGENTS.md, контракт |
| ai-api | Игрок 2 | FastAPI, LLM-агент с tool calling, fallback без LLM |
| ui | Игрок 3 | Streamlit, все вкладки, README, Docker |

## Архитектура
data/*.json → engine/ (чистые функции, тесты) → engine/interface.py (единый контракт)
  → api/ (FastAPI) и ai/ (агент: tools = функции interface.py)
  → app/ (Streamlit: импортирует interface + вызывает ai)
Принцип: числа считает только движок. LLM объясняет JSON и вызывает инструменты, сам не считает.
