## 5 Лаг

Реализованная доля полного эффекта инициативы с лагом `L`:

```text
realizedFraction = (8 - L) / 8
realizedEffect = fullEffect * realizedFraction
```

Например, эффект +16 с лагом 3 реализуется как `16 × 5 / 8 = 10`.

## 6 Синергии

| Пара | Бонус |
|---|---|
| M1 + M2 | T1 +2 в районе M1 |
| M10 + M12 | B1 +2 в районе M10 |
| M5 + M6 | E2 +2 в районе M5 |

Синергия применяется после лагированных эффектов. Бонус фиксированный и не масштабируется лагом. Если одна мера районная, бонус применяется к ее району.

## 8 Правила валидности

Сценарий валиден только при выполнении всех условий:

- решений ровно пять;
- все ID уникальны;
- общая стоимость не превышает 100;
- в одном направлении выбрано не более двух решений;
- районная мера имеет корректный район;
- городская мера не имеет района;
- нет несовместимых сочетаний.

Формулировка общего задания о пяти направлениях не трактуется как обязательная одна мера из каждого направления. Детальный датасет задает точное ограничение «не более двух мер одного направления», из которого следует покрытие минимум трех направлений.

Невалидный сценарий не получает Score. Валидатор возвращает список конкретных ошибок.

## 9 Формула

Для каждого района `d` и показателя `k`:

```text
I_after[d,k] = clip(
  I_before[d,k]
  + sum(realizedEffect[m,k])
  + sum(synergyBonus[k]),
  0,
  100
)
```

Бал района:

```text
D[d] = sum(weight[k] * I_after[d,k])
```

Средневзвешенный городской балл:

```text
D_avg = sum(populationShare[d] * D[d])
```

Количество критических значений:

```text
N_crit = count(I_after[d,k] < 40)
```

Итог:

```text
Score = 0.7 * D_avg + 0.3 * min(D[d]) - N_crit
```

Округление выполняется только для отображения. Внутренние расчеты используют полную точность JavaScript number.

## 11 Роль AI

AI получает только рассчитанный результат, дельты, вклад мер и допустимые альтернативы. AI может:

- объяснить результат;
- описать компромиссы;
- сравнить рассчитанные варианты;
- сформулировать рекомендацию.

AI не может самостоятельно вычислять Score, менять числа, придумывать отсутствующие эффекты или объявлять невалидный сценарий валидным.
