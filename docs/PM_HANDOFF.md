## Запуск доски

```sh
python scripts/status.py
```

Для частичного урезания U5 скрипт понимает `cut:timeline` и `cut:pareto`
в комментарии тикета. Полный статус cut исключает обе функции.
START — локальное время; переход через полночь поддерживается для пятичасового хакатона.
