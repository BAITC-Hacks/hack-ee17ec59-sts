# Статус проекта

_Последнее обновление: 2026-09-23_

## ✅ Работает

- Next.js App Router запускается из `src/app` и проходит `npm run build`.
- Сквозной flow работает в браузере: пять решений → валидация → детерминированный Score → районные последствия → AI/fallback записка.
- Эталонный сценарий дает расход 95/100, baseline 52.56 и Score 56.54; синергия M10+M12 отображается на экране.
- Без `OPENAI_API_KEY` приложение работает в fallback режиме, не ломая расчет.
- `src/lib/simulation` — актуальный числовой runtime. Python-файлы в `engine/` и `data/` сохранены как переносимый контракт/справочный каркас, но не используются UI.
- Материалы карты коллеги сохранены в `data/geo/`, `python_app/map_view.py` и `scripts/`; они не подключаются к MVP UI до отдельной проверки.
