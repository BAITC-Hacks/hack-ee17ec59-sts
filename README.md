# Аким на 5 часов

AI симулятор управления городом для HackAlem AI. Пользователь получает бюджет 100 условных единиц, выбирает ровно пять городских инициатив и сразу видит их влияние на районы Астаны, итоговый Astana Quality of Life Score и объяснение городских компромиссов.

## Главная идея

Все числа считает прозрачный детерминированный симулятор. AI получает уже рассчитанные результаты и превращает их в понятную записку акиму: что улучшилось, какие риски остались и какой сценарий можно рассмотреть следующим.

## Планируемый стек

- Next.js App Router
- TypeScript
- Tailwind CSS
- Zod для проверки данных
- OpenAI API для объяснений и рекомендаций
- Recharts или простые CSS диаграммы для визуализации

Проект не требует базы данных, авторизации или GPU.

## Локальный запуск

```bash
npm install
copy .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`. Если `OPENAI_API_KEY` не задан, экран результата использует встроенную детерминированную записку; расчет и числовой Score работают полностью офлайн. Для проверки production-сборки:

```bash
npm run build
npm run start
```

Быстрый demo flow: нажмите **«Загрузить эталонный сценарий»**, затем **«Рассчитать сценарий»**. Ожидаемый результат — расход 95/100 и Score около 56.54 при baseline 52.56.

## Docker (Next.js standalone)

Нужны Docker и Docker Compose **2.24+**. Запуск без ключа и без файла `.env`
использует fallback:

```bash
docker compose build
docker compose up -d
curl -I http://localhost:3000
docker compose down
```

Для AI скопируйте `.env.example` в `.env` (`copy .env.example .env` в Windows
или `cp .env.example .env` в Linux/macOS). Опциональные переменные:
`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`. Не коммитьте заполненный `.env`.
Compose читает его только при запуске контейнера; отсутствие файла допустимо.
Entrypoint также подставляет эти значения в прежние `OPENAI_*` имена для
текущего `/api/analyze`, если прежние переменные не заданы.

Сборка проходит в нескольких стадиях на `node:20-alpine`; финальный контейнер
запускает standalone-сервер от непривилегированного пользователя на порту 3000.
Исходники `.env*`, локальные зависимости и кэши в образ не копируются.

## Критерий готовности

Приложение должно позволять с нуля собрать валидный сценарий, рассчитать его, показать изменение показателей по районам и получить grounded AI объяснение. Новый разработчик должен суметь запустить проект только по инструкции в этом README.
